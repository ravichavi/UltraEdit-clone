# UltraEdit Clone
A fully responsive UltraEdit landing page clone built using HTML5 and CSS3. The project replicates the original website layout using Flexbox, CSS grid and media queries.
<br>
## Features
- Responsive Design for desktop,tablet and mobile
- CSS Flexbox
- CSS Grid
- Media Queries
- Semantic HTML5
- Clean UI inspired by the original UltraEdit Website
  
## Technologies Used
- HTML5
- CSS3
  
## Future Improvement
- Add JavaScript for a responsive hamburger menu
- Add animations and transitions
- Make the FAQ interactive
